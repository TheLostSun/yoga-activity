# Yoga Revolution – badge downloads

Static GitHub Pages site for the Yoga Revolution LED-wall game. The game's achievement screen shows a QR code that opens one of these pages; the page shows the badge and downloads it to the phone. No server, no tracking, no personal data.

| Badge | Page |
|-------|------|
| Yoga Champion (score ≥ 80) | `/badge1/` |
| Yoga Star (score ≥ 50) | `/badge2/` |
| Yoga Explorer | `/badge3/` |

Generated by `Tools~/make_badges.py` in the Unity project. Re-run it after changing the badge art, then commit and push.
